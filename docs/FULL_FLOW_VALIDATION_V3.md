## 发现并修复的问题

内部 Router 的主题词 `round outcome kill chain bomb plant retake` 被严格关系识别器误读为 `outcome kill chain`，进入不支持的关系语法分支。五张地图的 `round_flow` 子任务均没有证据，但综合 Critique 分数仍可能通过，因此仅看任务成功或 Verifier 不足以发现这类问题。

修复只为内部主题词加入分号，保持关键词与外部关系拒答规则。新增两项集成回归穿过真实 Router → Retrieve → KB / Graph 门控，同时验证伪造 `round_flow` 任务名也不能绕过不支持的关系条件。另用 45 组地图 / 队名组合确认同类误判被解除。

真实复测中，五张地图的 `round_flow` 均恢复 **4 条 Milvus + 4 条 Graph** 候选；按三种模式实际生成的计划合计，覆盖由 **12/17 提升为 17/17**。每场指标、Analyst 与 Coach 正文和基线完全一致，变化在历史检索证据与执行轨迹；没有改动 Critique 阈值。

页面复核还发现默认 69 节点的固定高度图谱裁切后续节点，已改为按内容确定画布尺寸并在有界区域滚动，保留节点标签的可读大小。favicon 缺失请求通过显式空图标修正。页面修复不改变分析 API 和来源数据。
