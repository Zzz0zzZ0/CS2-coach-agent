# TAGNet 开发训练试跑 v1

日期：2026-10-23。状态：Verified 开发训练链路；泛化、检索质量与 T 方模型仍未验证。

## 本轮完成

- 沿用已验证的 GPU 设置：普通 matmul IEEE FP32、cuDNN RNN TF32。单进程、batch=64，PyTorch 分配上限为总显存的 20%。
- 对发布 Dust2 CT 数据执行 5 种子（0/1/2/3/42）、两种目标、各 40 epoch 的对照，共 10 个训练运行。每个运行按自己的验证目标选 checkpoint，未根据测试诊断调参。
- 比较仅快照重建与“快照重建 + 下一帧四大区域比例预测”。模型与预测头具有相同初始权重，训练批次和预算相同。增加预测目标后 GRU 与情境编码器均有梯度。
- 通过前缀因果性、玩家联合置换、有限值及 match_id 划分互斥检查；现有快照与解析测试 11 项通过。
- 生成训练集拟合尺度的 B0 人数/距离特征和验证/测试查询候选，不计算未经审核的 Recall/nDCG。

## 数据与目标的准确范围

使用上游发布的 486/95/116 个训练/验证/测试回合，全部为 Dust2 CT。本轮沿用上游按比赛的拆分，更高层系列赛身份仍未完全核对。发布测试集已用于数值诊断；本轮属于开发实验，不是新的独立盲测。

目标沿用上游 A/B/Mid/CT 四区域比例，保留上游死亡玩家记录。它只是检验时序训练信号的小型变体，尚未实现泛化方案中的八区域、alive mask、共同地标特征或多地图共享表示。

seed=42 的烟测先完成，随后固定其余四个种子，未修改超参数。五种子标准差表示初始化敏感性，不是独立比赛上的置信区间。

## 结果

| 指标 | 平均值 | 五种子标准差 |
| --- | ---: | ---: |
| 仅快照目标：重建 MSE | 0.008302 | 0.000144 |
| 增加下一帧目标：重建 MSE | 0.008777 | 0.000269 |
| 增加下一帧目标：下一帧区域 MSE | 0.005057 | 0.000101 |
| 沿用上一帧区域的 MSE | 0.006810 | 固定基线 |

下一帧误差平均降低 25.74%，五种子范围 23.66%–27.15%；同时重建误差平均增加约 5.73%。这支持“时序模块获得可用训练信号”，但不能证明 GRU 优于静态预测器，也不能证明相似回合检索或教练建议更好。下一轮需要加入静态预测器及去情境对照。

资源：PyTorch 峰值分配显存约 52.56 MiB，峰值保留约 68 MiB；进程峰值工作集约 1486.64 MiB。显存数字不含驱动、上下文和其他应用。每个模型训练与选择约 10–11 秒，不含数据加载和初始化。

## 真实 CT/T 观测提取

原有本地 FURIA–Falcons 同系列三张地图（Mirage、Anubis、Inferno）各产生 21 个回合 × CT/T，共 126 条回合—阵营记录、630 个快照。没有缺失区域名，死亡玩家观测分别为 24/13/10 条。它们只能用于解析开发，不能把三张图拆成独立训练/测试。

64 Hz 和未校正暂停的 tick 偏移仍为显式假设；结构提取成功不等于时间校准完成。T 方尚未训练。

用户允许少量下载后，复用项目现有 `scripts.fetch_recent_demos` 和选择清单入口，限定一场系列赛，最多两张 Demo。选定仓库已有来源记录的 G2–Natus Vincere（2396940，Ancient/Inferno）作为下一批采集试点；该系列曾用于项目旧评测，不能重新称为全新盲测。实际下载状态以独立下载清单为准，不在此预先宣布成功。

本轮现已完成该系列的两张 Demo 下载：Ancient 19 个回合、Inferno 23 个回合，双方各产生 42 条五帧记录；文件 SHA-256 与仓库旧下载清单一致，见 [采集记录](../datasets/evaluation/tagnet_acquisition_2396940_v1.json)。没有继续下载第二场系列赛，未把新数据混入本轮训练或历史知识库。

下载过程中，旧浏览器入口的默认导航重试触发了同一压缩包的重复部分传输。现已设置 `retry=0`，新增离线回归覆盖，未再次下载验证以避免额外流量。最终只保留两份解压 Demo，临时重复文件由原下载器清理。

新增与解析相关检查 12 项通过，采集辅助检查 5 项通过。另一个既有 `test_fetch_script_accepts_reviewed_selection` 在本机 Windows 上被离线网络 fixture 阻断事件循环的本地 socketpair 初始化；这是环境/测试基础设施问题，尚未修复，不能称为全套测试通过。
