# P3情境对照：实现、结果和采用边界

2026-10-25；这是主计划的实验记录，研究主线仍由[CT_PUBLICATION_ROADMAP.md](CT_PUBLICATION_ROADMAP.md)维护。

## 已执行的比较

冻结原270个编码器，加入37维明确可观测的CT团队情境：五时刻己方装备总值的`log1p`（5维）、本回合开始前CT/T公开比分（2维），以及五时刻六类己方已记录投掷次数的`log1p`（30维）。投掷从冻结结束累计到各查询时刻；敌方完整装备、朝向、队伍/地图ID和未来结果均不作为新增特征。装备原已存在于节点输入，显式装备项属于重新赋权，不能写成新增信息。

每个距离分量除以源训练候选库中非对角窗口对的平均平方距离；常量源分量使用尺度1并记录标记。三个情境组等权，主对照采用`0.5×部署距离+0.5×情境距离`，保留0.25、0.75敏感性条件，以及仅装备、仅比分、仅道具、纯情境和纯部署对照。没有用测试结果或旧评分选择权重。

未知数据保留为未知。选用的源情境不全则该折对应条件不可用；查询情境不全则该查询对应条件不可用。所有方法保留同一源训练库，不通过删候选来提高分数。零投掷有效，无法确定阵营的投掷不能按零次处理。

设计是在已知旧开发结果和六个情境案例后固定的开发比较，不是独立盲测注册。实验设计和样本规划使用已安装的experimental-design、statistical-power技能，沿用主稿现有[Scientific Agent Skills引用](https://arxiv.org/abs/2609.00065)。没有新增依赖或批量安装技能。

## 计算验收

- [源侧小试](../datasets/evaluation/ct_context_retrieval_pilot_report.json)：43个源验证窗口，6种神经条件和3个对照；冻结权重，只做编码推理。峰值显存78.1 MiB、RAM约1.04 GiB。计算计时1.62秒，不含解释器启动和输入预检，不作为端到端时延。
- [完整排名对照](../datasets/evaluation/ct_context_retrieval_report.json)：315个方法/折/种子条目，131,130个查询—方法—策略记录。计算13.61秒、峰值RAM约101 MiB，压缩输出约9.8 MiB。新排名仍无新增独立评分。
- [源拟合模式对照](../datasets/evaluation/ct_context_pattern_report.json)：315份聚类，45.19秒、峰值RAM约169 MiB。每次K只在源训练期从2–6选择；数值簇ID不命名职责。既有不含情境的神经模式结果保留原样。
- 四项情境接口检查覆盖源侧归一化、未知与零、观战信息排除、加权距离与联合向量一致性、稳定排序及空候选标记。完整重建配方与原始数据均不改写。

## 一致性升高不等于战术效果提高

| 条件 | G3跨种子ARI | G4跨种子ARI | G4分配覆盖 |
| --- | ---: | ---: | ---: |
| 原Graph+GRU | 0.502 | 0.406 | 93.0% |
| Graph+GRU + 情境 | 1.000 | 0.995 | 90.2% |
| 原MLP+GRU | 0.353 | 0.520 | 86.0% |
| MLP+GRU + 情境 | 0.983 | 0.988 | 91.3% |

ARI只在共同获分配且双方至少有两个簇的查询上计算；不同条件的有效子集不同。覆盖是查询×种子的诊断比例，不是独立样本准确率。纯情境与统计对照没有神经种子ARI，记录为不适用。

[事后分量核查](../datasets/evaluation/ct_context_dominance_report.json)发现，G4完整Graph+GRU+情境的质心平方分离，平均由部署编码贡献2.66%、装备66.55%、比分6.34%、投掷24.45%；其查询分组与纯情境簇的ARI为0.987。该结果解释的是当前标准化空间中的分离，不是因果重要性。不能把稳定的两个资源簇改称为战术职责。

因此保留分开的部署模式和情境属性；联合聚类作为已完成对照保留，不取代原部署模式。固定权重的检索仍作候选比较，是否有参考价值需要任务相关证据。

## 旧人工材料的同片段辅助复查

[来源核查](../datasets/evaluation/ct_existing_judgment_audit_report.json)逐一校验6份原回传、对应题包内容哈希，以及43个已发片段对的五帧坐标、地点、生命和装备；未改原分数、理由、弃评或完成状态。部分旧候选属于当前模型的源验证集，因此按当前源训练库规则排除，原评分仍留档。

严格子集是17个原协议完整数字片段对、3个查询；所有已有数字的敏感性子集有30条参考价值和29条相似度、5个查询。只在这些已评分且合格的候选中计算nDCG@min(5,N)。未评候选不填零；全零理想增益或不足两候选时不计算。先平均同一查询的神经种子，再等权平均查询。没有显著性检验、没有把种子当独立评审，没有混入AI银标。

[完整结果](../datasets/evaluation/ct_existing_pool_replay_report.json)保留全部228种子集/维度/方法/策略汇总及912个按查询汇总的条目，包含静态、输入消融及权重敏感性条件。本表展示两个完整时序编码器和固定的直接对照，不选择最好权重。

小样本中情境组合优于各自原编码器，但纯情境在部分维度更好；不存在稳定的图模型优势。旧材料未显示新增道具/比分，评分者身份独立性未核实，候选池又由旧方法选择。这些只能作为信息有限的开发期辅助观察，不能改写成全候选库检索性能或新的独立战术确认。
