# 中英文与别名校准 v1

本轮是已观察开发语料上的受控实验。固定 1,019 回合、原有 16 个语义问题，补齐中英文共 32 个表述；两种语言共享相同参赛主体、事件定义、范围和相关回合。翻译与标签均由 AI 辅助审核，不属于人工 gold。

当前已冻结 [运行协议](../datasets/evaluation/fair_calibration_v1_protocol.json)、[成对问题](../datasets/evaluation/fair_paired_queries_v1.json)、[逐源标签](../datasets/evaluation/fair_paired_qrels_v1.json) 与 [适配配置](../datasets/evaluation/fair_query_adapters_v1.json)。逐题翻译核对在冻结前纠正过一处无答案题的事件译法；最终 n04 的两种语言均问闪光致盲，不是下包。

四组设置在同一次运行中全部报告：原始查询 + 精确实体、术语补充 + 精确实体、原始查询 + 别名、术语补充 + 别名。每组同时运行无实体约束和有实体约束的 BM25 / dense / RRF，以及单列 SQL / 回合事件路径参考，共 1,280 条结果。结构化参考额外得到 event_kind，不代表生产 GraphRAG。

正文为英文，所以中文适配采用固定 CS2 术语补充，保留原自然语言查询；BM25 与 dense 接收相同适配文本。它不是通用中文分词器或翻译器，也不读取标签、事件槽、比赛 ID 或 query ID 生成检索词。实体别名来自此前已审核的 Spirit / Team Spirit、Falcons / Team Falcons 等价关系，仅做完整名称匹配，不把 Academy 等相似名称合并。

不根据结果调词表、top-k、融合参数或阈值。先检查原 160 条排序与前一版逐条相同；分语言报告时各有 11 个正例、5 个负例，合并报告先按语义问题平均，不能把译文当作额外独立样本。候选相关回合的覆盖率与最终 top-k 排序分开分析；别名补全不保证 nDCG 上升。

生产 SQLite / Milvus 不写入，常驻服务不重启，文本模型调用为 0。语料向量使用相同本地模型与分块方法，要求 SHA 与前一次冻结结果一致；本轮还会保留逐题有效查询、来源 ID 与分数。

```bash
PYTHON_DOTENV_DISABLED=1 HF_HUB_OFFLINE=1 .venv/bin/python -m scripts.calibrate_fair_retrieval \
  --protocol datasets/evaluation/fair_calibration_v1_protocol.json \
  --model-dir /absolute/path/to/the/frozen/local/model \
  --output data/evaluation/calibration_reproduction/report.json
```

输出必须是新路径，协议验证输入、源码和模型哈希。源码修改后需要检出该冻结版本或建立新协议。复现需要本地 1,019 回合语料、图谱及对应模型缓存。


## Verdict

通过本轮受控校准的工程验收。冻结提交为 `d2725e9`，157 项离线测试及对应 CI 通过。全部 1,280 条结果完成，原始 160 条排序逐条一致；语料向量哈希与上一版一致。见 [完整结果](../datasets/evaluation/fair_calibration_v1_report.json) 与 [运行后审计](../datasets/evaluation/fair_calibration_v1_audit.json)。

## 实际结果

下表均开启共同实体约束。每种语言 nDCG@5 的分母为同一组 11 个有答案问题，表格每格为 **英文 / 中文**。

| 配置 | BM25 | Dense | Dense + BM25 RRF |
| --- | --- | --- | --- |
| 原始 + 精确实体 | 0.6425 / 0.6425 | 0.9139 / 0.8513 | 0.8415 / 0.7873 |
| 术语 + 精确实体 | 0.6425 / 0.6425 | 0.9139 / 0.8584 | 0.8415 / 0.8428 |
| 原始 + 实体别名 | 0.6580 / 0.6580 | 0.9426 / 0.8359 | 0.8477 / 0.8028 |
| 术语 + 实体别名 | 0.6580 / 0.6580 | 0.9426 / 0.8991 | 0.8477 / 0.8407 |

按语义组先平均两种语言，原始配置到组合配置：BM25 0.6425 → 0.6580，dense 0.8826 → 0.9208，RRF 0.8144 → 0.8442。改善属于这组已观察开发题，不能推断总体提升。这里 dense 优于 RRF，不能预设融合一定更好。

中文术语补充 **没有改变本轮有实体约束 BM25 的任何一题 top-5 排序**；BM25 的改善来自别名处理。别名补全也不保证单题排序更好：Spirit Ancient 下包题 p10 的中文 dense nDCG，原始为 0.3008，单独加术语降为 0.2140，单独加别名降为 0.1312。组合设置在本轮未出现相对原始的单题 nDCG 下降，但不能据此忽略两个单独消融中的失败。

| 语义题 | 精确匹配时可用的相关回合 | 别名处理后 | 审核相关总数 |
| --- | ---: | ---: | ---: |
| p09 Falcons / Dust2 / 投掷物 | 41 | 64 | 64 |
| p10 Spirit / Ancient / 下包 | 26 | 58 | 58 |

合计补回 55 个相关回合；翻译版本共享这些来源，不重复计数。别名只扩展显式名称的等价形式，没有改变地图、比赛或回合范围。

## Findings

- **minor / high，中文 BM25 基线仍不足**：`fair_calibration_v1_report.json` 中术语补充前后中文 BM25 top-5 全部相同。当前领域词表未证明能改善这一词法基线，不能称其为已经充分适配中文的强基线；后续需要另行冻结词法表示实验，不能在本轮结果上暗改参数。
- **major / high，当前题组不能支撑正式泛化结论**：11 个正例中，p02、p03、p04、p08、p09 在范围与别名实体过滤后，候选集合的相关比例为 100%；其余 p11 也达 57/58。这些题对正确候选之间的排序区分度很低。
- **major / high，无答案题只覆盖空范围**：全部 5 个无答案语义题在共同范围 / 实体过滤后候选数为 0。实体约束开启时误召回为 0，只能说明显式范围约束生效，不能证明在有效选手、地图和比赛内能识别“所问关系不存在”。

后两项是研究证据边界，不是程序崩溃。完整 [难度与回合覆盖数据](../datasets/evaluation/fair_calibration_v1_audit.json) 保留每题候选比例和 Recall@5 的理论上限；大量相关回合时 Recall@5 的上限本身很低，不能脱离相关总数解读。

## Verified

- 1,280 条结果的来源均位于正确候选范围，候选数与相关回合覆盖计数全部复核通过。
- 关闭实体约束时，别名改动对 320 条对照结果没有作用。
- 中文词表没有改变 320 条英文对照结果；256 条结构化参考结果也未受到词表影响。
- 原 160 条冻结排序完全复现，未修改原查询、旧标签、旧报告、SQLite 或 Milvus；没有远程模型调用。
- 校准器、测试、协议、模型及输入哈希均保留。新审计工具可独立复核范围和上述不变量。

## Risks

本轮只有 16 个语义问题，其中翻译版本由同一 AI 核对，标签也由共享解析事实支撑。术语表来自已观察项目领域，属于开发期适配。没有独立人工标签、未见问题验证或总体置信区间；显式实验槽并未测量自然语言实体解析能力。此结果可以作为方法校准与失败分析展示，尚不能包装成正式高质量 benchmark 的最终结论。

## Next actions

优先增加**同一有效选手 / 战队、同一地图内**的可区分问题和无答案反例：明确动作主体、阵营、对手、先后顺序、补枪窗口，以及跨回合分子分母。保留现有 16 题作为简单回归，用真实事件逐源审核新题；在运行候选方法前冻结问题和标签。已有两场新增比赛先用于整场隔离的回归研究，不重新声明为未见样本。

随后用新题检查字段表示和词法基线，补充多语 dense 对照；不为了提高当前小题组的分数继续调整词表。生产检索实现本轮未变更，常驻服务仍未重启。
