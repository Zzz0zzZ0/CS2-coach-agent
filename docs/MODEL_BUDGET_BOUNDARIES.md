# 模型预算与故障边界

更新：2026-09-07。此阶段只增加生产模型调用的本地边界；没有远程模型调用、没有修改既有盲评结果或历史图谱。

## 共享入口与记账口径

`get_llm()` 返回带预算限制的现有模型客户端，覆盖 HTTP、Celery、CLI，以及启用后的 Supervisor、查询改写、Critique 和文本提取。同步 Prompt 链、异步调用和 `bind_tools` 共用一个 SQLite 账本。没有新增依赖。

默认账本为 `data/runtime/llm_budget.sqlite`；相对路径始终按项目根目录解析，同一项目的进程共享该文件。默认本地上限 30,000 token、100 次尝试，可在首次使用前通过 `LLM_BUDGET_TOKENS` / `LLM_BUDGET_MAX_CALLS` 设置，0 表示关闭调用。首次预留持久保存上限，之后配置不一致直接拒绝，不静默清零。重启进程、更换密钥、更新输出长度都不会重置累计量；不按天自动恢复。

这不是账户的 1,000,000 token 免费额度余额。账本从启用时开始计数，不补造历史用量；此前盲评的 4,939 token 继续保存在原实验报告中。提供商剩余额度返回 null。其他项目、其他机器和远程 embedding 不在本账本范围，当前默认本地 FastEmbed。若需要保证不进入付费区间，必须另行确认提供商端免费额度及计费限制；本地估算无法证明账户剩余免费额度。

## 调用前后行为

1. 按文本消息和工具 schema 的 UTF-8 字节数，加 2,048 余量及输出上限预留。只支持当前使用的文本输入；不支持的输入和调用参数在联网前拒绝。
2. SQLite `BEGIN IMMEDIATE` 原子检查总额度、尝试次数及未结算请求；先持久写入请求 ID、时间、模型、输入哈希、预留量，再调用网络。只存哈希，不存提示词、密钥或提供商错误正文。
3. 成功且有有效 usage 时，以提供商 `total_tokens` 结算并释放多余预留；实际用量超过估算时照实记录并停止后续请求。字节估算是保守策略，不是精确计费保证。
4. 超时、取消、提供商拒绝、其他请求错误或 usage 缺失时保留预留，后续远程调用停止。进程崩溃留下 pending，同样不自动重放。账本损坏、锁超时或写入失败均先拒绝网络调用；若结算失败，先前 pending 仍阻止后续调用。
5. SDK 固定零重试，模型固定 `qwen3.8-flash`，thinking 关闭；配置其他模型不会自动切换。异步调用另有整体超时，同步调用使用 SDK 超时配置，最大配置 120 秒。

只允许同一账本同时有一个未结算请求；并行竞争者采用原有规则降级，当前不增加队列。网络中断不能证明提供商没有计费，所以不会将未知用量当成零释放。单个提示超过剩余预留只拒绝该次请求，不消耗调用次数，更小请求仍可尝试。

## 查看与恢复

页面显示本地剩余额度、尝试次数、已报告用量、未结算预留和暂停原因，支持手动刷新，当前任务状态变化时也刷新。`COACH TOKENS` 只表示 Coach 单次返回的用量，未知时为“—”；累计用量以共享账本为准。

只读状态接口：

```bash
curl -s http://127.0.0.1:8001/api/settings/llm/budget
```

查看状态不会新建账本，也不会调用模型。`remaining_local_allowance` 是本地上限减已报告用量和未结算预留，不是提供商余额；`accounting_complete` 只说明本账本是否还有未知用量。

故障后保留账本，先核对提供商实际用量、账户额度及请求是否仍执行。当前没有清零、自动解锁或自动恢复接口；恢复需经过明确的对账操作和运维变更，不能删除账本或更换路径来绕过停止状态。正常执行中的 pending 会在成功结算后解除；真正中断的 pending 不会仅因超时过期而被释放。

代码更新需要 API / Worker 加载新版本；旧进程不会凭磁盘代码修改获得新保护。本轮只启动了独立临时预览服务，未重启原服务。

- **结论：通过本地工程验收。** 共 140 项离线测试通过，前端生产构建通过；测试禁止网络，新增 15 项预算相关用例。
- 覆盖真实 Prompt 链和 Coach 工具路径、零预算 / 过小预算、调用次数、配置变更、同步错误、异步超时与取消、429、缺失 usage、估算超出、账本损坏、更换密钥保持累计量。
- 三个独立进程竞争同一文件，仅一个成功预留；进程结束后该 pending 仍阻止重放。完整 AnalysisPipeline 在预算拒绝时保留指标、当前证据和规则 Coach 报告，模型调用次数为 0。
- 浏览器验证初始预算、离线模拟提供商拒绝后的暂停提示、刷新、未知 Coach 用量和未结算预留。模拟账本位于独立临时目录，未写生产账本。

- 剩余限制：未验证提供商真实免费余额或真实断网计费；没有跨机器账本或自动对账恢复。未将这些范围写成已完成能力。第八项真实人工评分继续待补。
