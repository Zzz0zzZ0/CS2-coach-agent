## 冻结排序的事后评分

后续原始 Demo 核验发现历史 4 图混入赛前刀局。以下分数作为旧冻结语料记录保留，历史数据修正后必须重算，暂不用于最终展示结论。详见 [新比赛带来的发现](NEW_MATCH_VALIDATION_V3.md)。

正例 nDCG@5 对 11 题取均值；误召回只对 5 个无答案问题计数。中英文分组与每题数据保留在[完整报告](../datasets/evaluation/fair_ai_posthoc_v1_report.json)。

| 方法 | 无实体约束 nDCG@5 | 有实体约束 nDCG@5 | 无答案误召回：无 / 有约束 |
| --- | ---: | ---: | ---: |
| BM25 unicode61 | 0.6117 | 0.5963 | 3/5 → 0/5 |
| MiniLM 分块均值 dense | 0.5636 | 0.9099 | 3/5 → 0/5 |
| dense + BM25 RRF | 0.8301 | 0.8226 | 3/5 → 0/5 |
| SQL 条件参考 | 0.4545 | 1.0000 | 3/5 → 0/5 |
| 简化图路径条件参考 | 0.4545 | 1.0000 | 3/5 → 0/5 |

SQL 和图路径参考获得人工指定的事件条件，不代表生产 GraphRAG 的自然语言理解能力；两者结果相同不能证明图方法增益。当前结果显示实体约束在这批无答案问题上有效，但 RRF 未一致超过 dense，BM25 加约束后的排序指标还略有下降。尚不能据此宣称某种架构普遍更好。

每题相关回合可达 99 个，top-5 的 Recall 上限受相关集合大小限制。报告保留 Recall@5 与分母，不把较低的绝对数值直接解释为系统整体不可用；nDCG@5=1 也不表示完整召回。

两个核算实现共同依赖已有 Demo 解析事实，不能独立发现共享解析错误。本轮由开发助手进行事后审核，既不是盲审，也不是人工金标准或新比赛泛化结果。中文词法基线与 dense 表示仍需在开发集完善。
