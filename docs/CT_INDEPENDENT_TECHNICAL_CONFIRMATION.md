# P4独立技术确认预案

2026-10-26；状态：12系列采集、原生输入核查和冻结权重技术确认均已完成。主计划仍为[CT_PUBLICATION_ROADMAP.md](CT_PUBLICATION_ROADMAP.md)。

[采集记录](../datasets/evaluation/ct_independent_acquisition_preflight.json)保留了先前内存不足的预检。释放内存后，隔离的普通浏览器成功获取82/85个比赛页面，按既定规则选出六图各两系列、每赛事四系列，完成[清单冻结](../datasets/selections/ct_independent_cohort.json)及[权重/技术协议冻结](../datasets/selections/ct_independent_confirmation.json)。Python HTTP下载入口仍受限制，采用项目现有普通浏览器方式采集。候选含5月和10月赛事，属于新系列确认，不能称时间向前留出；所选档案没有预列的Cache补充。

## 要回答的问题

本子协议检验冻结的CT观测表示在新系列上的技术表现。主要技术比较为G4完整Graph+GRU与相同完整输入的MLP+GRU；原六个神经条件均保留，其他对照作描述性分析。此子协议不能代替整篇论文的模式解释、部署检索和独立语义判断。

主要量：先在每个新系列所选地图内平均三个种子和全部合格窗口的共同重建损失，再计算`log(Graph+GRU均值 / MLP+GRU均值)`；最后等权平均六张地图的系列均值。负值表示图条件损失较低。一个系列只贡献一张主分析地图；帧、回合和种子都不计为独立系列。

窗口沿用当前五时刻和至少一个存活CT的条件，保留早结束、全灭、时钟不一致、字段缺失等排除记录；不把本结果推广为所有回合或实战教练效果。

## 精度依据，而非任意补几场

[计算报告](../datasets/evaluation/ct_independent_precision_report.json)采用六图等额、独立正态且同方差的系列残差作规划近似，残差自由度为`N−6`。目标是95%区间的半宽0.05对数单位（约5.13%的乘法比），并考察80%达到该宽度的概率。这是技术分辨率设定，不是已有战术价值阈值，也不是优效检验功效。

| 假设图内系列残差SD | 方差乘数1 | 方差乘数1.5 | 方差乘数2 |
| --- | ---: | ---: | ---: |
| 0.02 | 12系列 | 12系列 | 12系列 |
| 0.05 | 12系列 | 18系列 | 18系列 |
| 0.10 | 24系列 | 36系列 | 42系列 |
| 0.15 | 48系列 | 66系列 | 84系列 |

九个旧开发系列的对数比SD为0.0288，但存在重复队伍和重叠训练折，不能据此认定总体SD。规划故同时检查更大的0.05、0.10、0.15及方差膨胀场景。方差乘数不是从数据估得的ICC修正。

在理想模型SD=0.05、12系列的情形，95%区间半宽在0.05以内的概率约93.9%；SD=0.10时明显不足。因此12系列只能是预算内的确认队列，不能承诺足够发表或充分验证战术泛化。报告实际区间和不确定性，不在看过模型效果后追加到显著为止。

## 采集与隔离规则

计划主队列为12个新系列，每图2系列，每系列只保留一张主分析Demo。优先分散到至少3个已结束赛事，每赛事最多4系列；同一地图的两系列来自不同赛事。同一系列、同一文件内容和来源别名不得进入两侧。重复队伍和赛事的依赖如实记录，不据此声称完全独立。

先读取公开赛事、地图和下载元数据，按事先确定的日期/系列ID顺序和地图配额选样，记录全部替补。具体主清单、替补顺序、源训练/验证/候选库及权重哈希均须在解析新模型输出前冻结。只按下载、格式或预先规定的数据质量原因替补，不按损失、检索结果或胜负挑选。

G4使用既有对应留出地图的冻结模型与源训练候选库；所有方法同库。已接触过的六图依然只能称“训练留出地图”，不能称研究者从未见过。G3如开展另行列明固定源模型及用途，不从新测试挑选源折或模型。

若所选档案同时含有开发训练从未使用的其他地图，可在冻结清单中预先指定一份为独立的描述性新地图补充，不计入六图主样本、不调模型、不补地图专用职责映射，也不把同系列多图当新系列。不得为好看的结果临时选择该地图。

## 资源与停止规则

- 每次一个下载、一个解析进程，不与训练竞争；开始解析前可用RAM至少2 GiB，后续操作保留1.5 GiB余量。
- 主队列最多12个系列/12张保留Demo；如预先指定同档案的新地图补充，保留Demo最多13张。
- 新归档累计下载上限6 GiB，保留Demo总量上限6 GiB，单张保留Demo上限768 MiB；单个归档上限1.5 GiB，瞬时解压空间单独预检。
- 元数据阶段列出最多6个替补；包括失败重试在内最多18个归档请求，累计字节上限始终有效。下载失败不构成增加预算的许可。
- 遇到容量、内存或访问问题，先记录并告知；不越过上限。只清理本轮自己生成、未被证据引用且可重建的临时文件，保留原始数据、回传和冻结权重。

新数据到齐后的主分析区间按六图固定效应、共同图内残差的t区间给出，并同时报告逐图结果、异方差敏感性及重复队伍/赛事限制。该区间依赖模型假设，不称为随机化因果估计。没有新语义判断的排名保持未评分，旧人工题继续暂停。


## 本轮实际结果

[采集与核查报告](../datasets/evaluation/ct_independent_acquisition_report.json)记录12系列、六图各两系列、每赛事四系列。247个完整回合保留246个合格CT窗口，1个因20秒前结束排除。原Mirage档案分为p1/p2，按预列规则用2398722替换2398721，未拼接片段，也未根据模型效果换样。三个原生队名缩写差异经完整五人阵容核对，并只使用有来源的NAF-FLY/NAF、Techno4K/Techno别名；全局队名服务和模型输入未改。

共14个归档GET尝试、13个成功档案，保留12张主分析Demo。实际归档载荷5.161 GiB；含失败请求保守预留的计账5.403 GiB；保留Demo3.883 GiB，均在原预算内。清理了本轮浏览器下载的11个无关CRX临时包，共65.42 MiB，原始Demo、归档、权重及证据保留。

[冻结技术确认结果](../datasets/evaluation/ct_independent_confirmation_report.json)来自108份源G4权重的前向评估，无新训练或目标侧选模。主要Graph+GRU/MLP+GRU几何平均损失比1.01576，条件模型95%区间[0.99586,1.03606]；预定异方差敏感性区间[0.98218,1.05049]。两者均包含持平，未支持稳定图优势，也不能据此宣布等效。六个神经条件及全部种子均保留。

GPU评估循环约3.67秒（不含导入/解析），峰值显存77.6 MiB、进程峰值RAM约1146 MiB；原生输入导出峰值约677 MiB。误差指标仍是共同重建代理，不是战术相关性、职责正确率或实战教练效果。

下一项为源拟合模式向新系列的迁移及情境检索对照。现有人工题继续暂停；新排名不得填入推测的人类分数。
