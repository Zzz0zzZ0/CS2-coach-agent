## Risks

- 标签尚未独立审核；软件只能校验审核记录完整性，无法证明审核者独立性或结论质量。
- 文本方法的中英文处理存在差异；结构化参考额外接收事件类型，不支持跨表算法优越性结论。
- 当前耗时为本机热态快照；单场新比赛不足以估计跨比赛性能或战术价值。
- CI 权限问题已解决：正式工作流首次远端执行通过，96 项测试与前端构建成功。详见 [离线验收记录](OFFLINE_VALIDATION.md)。
